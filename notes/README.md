# 區域脈絡筆記

導讀的 zh-CN 與 en 各有一段區域段落，寫各地的法規、服務能不能用與既有的類似制度（見 `guides/posts.md`「三個語系」）。同一類題目反覆出現，例如加密、扣押取證、實名制、年齡驗證，每篇都重新查證與審稿太花成本。查證過的內容寫在這裡，之後的稿件直接引用。

這個目錄不會建置成網頁，只給寫稿的人與 AI 協作工具讀。

## 一份筆記的格式

一個主題一份檔案，例如 `compelled-decryption.md`。檔案開頭寫主題的範圍，接著依地方分小節，每一條寫：

- 事實，一句話寫完，含適用範圍，例如只限國安案件、只限刑事案件
- 照錄的原文句子
- 文件全名、網址與文件的日期，草案寫明是草案
- 查證日期

查不到的寫明查不到，二手來源與一手來源分開標示。不寫人名，不寫哪個地區、哪個族群的人在用什麼工具。

## 引用與更新

- 稿件引用筆記時，把筆記列的來源加進該版本的 `sources`，句子照筆記的範圍寫，不延伸
- 查證日期超過 6 個月的條目，引用前先回原文確認，有變動就更新條目與查證日期
- 筆記沒有的內容，寫稿時另外查證，查完先寫進筆記，跟稿件放在同一個 PR
- 筆記本身照貢獻者百科的寫作規則寫，交稿前用 `docs_style_lint.py` 掃過
