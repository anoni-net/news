關於新聞導讀

anoni.net 新聞導讀如何選題、查核、更正與追蹤後續，三個語系的差異，以及回報錯誤的方式。

anoni.net 新聞導讀由台灣的匿名網路社群 anoni.net 編寫，整理國際間隱私、匿名網路與網路審查的新聞。我們比較熟悉科技與開源生態，所以從這個角度讀新聞。每篇先用新聞寫法交代發生什麼事、誰受影響，再用「導讀觀點」說明背後的技術、讀者現在能做的第一步，以及要付出的代價。

選題

候選新聞來自約三十個固定來源，包括數位權利組織、資安研究團隊、開源專案與媒體，另外參考科技社群的每日精選。維護者先依標題挑選，再讀原文確認能否寫出導讀觀點。優先選讀者今天就能下載、設定或照著做的題目，以及會改變既有做法的技術與政策變化。

查核

每一句事實都要能在原文或官方資料找到出處，找不到出處的句子會拿掉，或改寫成推論的語氣。工具與服務的現況，包括版本、價格、支援的平台與地區、有沒有中文介面，在寫稿當天回到官方頁面確認，跟原文不同時以官方資料為準。

每篇用到的原文與資料都列在文章的「原文」區塊，附上出處與日期。導讀觀點為了比較各地狀況而查的法規與統計，也列在同一個區塊。

更正

文章發布後發現錯誤或資訊過時，我們會同時修正三個語系。稿件放在公開的 GitHub repo，每一次修改的內容與時間都可以查到。

事件的後續

隱私與審查的新聞常延續好幾個月。法案會修正、表決，功能會從測試版正式推出，有些事件過了一段時間才出現新的調查結果。導讀過的事件如果有新進展，我們會另寫一篇後續的導讀。後續的開頭用一句話交代前情，沒讀過先前的文章也看得懂。先前那篇的標題下方會出現最新一篇的連結，文末也列出同一事件的每一篇導讀，從任何一篇進來都能看到最新的進展。

三個語系

每篇同時發布正體中文、簡體中文與英文三個版本，事實以正體中文版為準。導讀觀點則依讀者的處境改寫。簡體中文版以中國境內與海外的讀者為對象，寫明在中國能否使用、如何取得。英文版的導讀觀點篇幅較長，加入亞洲各地法規與服務現況的比較，新聞的主角是美國或歐洲的產品時也一樣。三個版本的導讀觀點因此不完全相同，各自引用的資料列在各自的原文區塊。

署名

文章預設以「anoni.net 社群」署名，不寫個人，不想留下個人痕跡的作者也能參與。內容是否正確，由可查證的出處與公開的修改紀錄來檢驗。

回報錯誤

發現事實錯誤、過時的資訊或翻譯問題，歡迎在 GitHub 開 issue，寫明是哪一篇、哪一句，能附上出處更好。不想用 GitHub 帳號的人可以寄信到 whisper@anoni.net，建議用 PGP 加密。

朗讀

想用聽的讀者，可以使用瀏覽器與作業系統內建的朗讀功能。iPhone 的 Safari 有「聆聽網頁」，文章頁的結構讓它只念導讀本身，跳過原文清單與頁尾。這個選項會依頁面與裝置的語言決定是否出現，看不到時可以到「設定 > 輔助使用 > 閱讀與朗讀」開啟「朗讀螢幕」，它會連同頁首與頁尾一起念。本站沒有另外放朗讀按鈕，因為那需要 JavaScript。部分瀏覽器的朗讀使用線上語音，文章內容會送到瀏覽器廠商的伺服器，在意的話請選擇裝置本機的語音。

閱讀量與隱私

本站以自架的 Umami 計算閱讀量，不使用 cookie，瀏覽器開啟「請勿追蹤」或 GPC 時不送出。除了頁面瀏覽，也計算三種點擊：原文區塊的連結、訂閱入口（記錄管道是 RSS、電子報或 Bluesky，位置在刊頭、文章末或頁尾）、首頁的文章連結（記錄來自焦點或時間軸）。點擊事件不含連結的網址。頁面不需要 JavaScript，也不載入站外的字型與資源。onion 版本不載入統計，網址在每一頁的頁尾。
